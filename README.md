# BitSliceInverse

Exact grouped aggregation over encoded columns: rank cubes, conjunction cubes,
value clustering, block summaries, and budget-aware routing.

Requires Python 3.10+, a C++20 compiler, and Linux for the full experiment suite.
Reference hardware: two AMD EPYC 9554 CPUs and 503 GB RAM.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/build.py
python scripts/check.py
python scripts/prepare.py ig2
python scripts/benchmark.py ig2
python scripts/run.py router
```

[Experiment commands](docs/experiments.md) cover NYC taxi, TPC-H, scale,
parallel construction, output, correctness, and engine comparisons.
Public inputs are downloaded or generated by the preparation scripts.
Run outputs are written under `work/`; frozen measurements are in
`research/real_decoders_20261025/receipts/`.
